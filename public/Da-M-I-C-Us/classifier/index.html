‹ VES AI Key Classifier Policy Maker Compare One-page sheet
Exploration shell: Compare is the home. The left side says what the deployment is; the right side says what the organisation permits; the circle between them shows, sector by sector, whether the deployment sits inside that policy. Fill both sides to compare — a white sector means that dimension is still undecided on one side or the other.

CLASSIFICATION — what it is

or Classify… (guided reference tool)
Factual side. Four-part strings or Use “unset” are capability classifications — there is no Use to compare until it is set. Typing updates the selection as you go. Composites (+) paste in Data and Model; quick entry covers single values only. The “or Classify” link opens damicus-v2_classifier_r4.html from the same folder as this file.

POLICY — what is permitted

Define policy… (reference tool)
Normative side. A policy is a permitted set per dimension: pick one or more codes, or ★ ANY for a wildcard. Paste the string the Policy Maker’s Copy policy string button produces, or pick a common policy above. “Define policy” opens damicus-v2_policymaker_r10.html from the same folder as this file.
